Sobre o projeto

O MapsIF é um projeto criado por alunos do curso técnico de Informática do IFPB Campus Santa Luzia (turma 2024–2026). A proposta é simples: levar quem ainda não conhece o campus por um passeio em 360°, ambiente por ambiente, bloco por bloco.

O aplicativo foi desenvolvido em Java para Android, usando o Pannellum para os visualizadores 360° dentro de uma WebView, e organiza o tour seguindo a mesma divisão física do campus: Bloco A e Bloco B, cada um com seus andares e ambientes.

Este projeto também possui uma versão web acessível em: https://macedo-hub.github.io/mapsif/

Instalar é simples — leva menos de dois minutos

Como o MapsIF ainda não está na Play Store, o Android pede uma confirmação extra antes de instalar. Preparamos um passo a passo com print de cada etapa.

  • 1 Baixe o arquivo .apk pelo botão
  • 2 Autorize a instalação de fontes desconhecidas
  • 3 Confirme o aviso do Play Protect
  • 4 Abra o MapsIF e comece o tour
